# Data Config Artifacts

## `fine1043_to_coarse78_pengyu.csv`

Hard-coded lookup table for assigning each fine 1043-site row to a coarse 78-group ID.
This table is derived from `data/pengyu/calibration/gamma_fit_1043.geojson`.

- `fine_index_1based`: 1-based feature order in `gamma_fit_1043.geojson`
- `coarse_group_id_78`: corresponding `id_group` value
